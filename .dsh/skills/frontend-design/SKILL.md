# Frontend Design · 界面审美与动效

一个"看起来像被认真设计过"的界面，来自**一个明确的概念 + 少数被坚持执行的原则**，
而不是更多的渐变、更多的圆角、更多的阴影。

## 0. 先定概念，再动 CSS

写第一行 CSS 之前，用一句话回答：**这个界面的隐喻是什么？**

本项目（迹录 AgentTrail，AI 会话档案库）的答案是：**纸面档案 / 技术台账**。
它决定了所有具体选择：

| 概念 | 落地 |
|---|---|
| 纸 | 暖白底 `#f4f1e9`，卡片近白 `#fffdf8`，发丝级描边而非重阴影 |
| 台账 | 表格、等宽数字、编号、`kicker` 小标、发丝分割线 |
| 印章 / 墨 | 深墨黑作主按钮与标题，玉绿作唯一强调色，朱红只用于危险 |
| 档案盒 | 16px 圆角容器 + 顶部细线，标签用小型大写 + 字距 |

换主题时先换这张表，再改 CSS 变量。**不要在浅色背景上直接复用深色主题的透明度写法**。

## 1. 层级：靠字号、字重、间距，而不是靠颜色

- 一个页面最多 **3 级** 文字层级：标题 / 正文 / 辅助。第 4 级用"存在感"解决（缩进、分割线、留白）。
- 正文字号 ≥ 13px，辅助文字 ≥ 11px。**8–10px 的中文在任何屏幕上都是事故**。
- 标题用 `letter-spacing: -.02em ~ -.04em` + `line-height: 1.15`，正文 `1.6`。
- 中文正文不要 `text-transform: uppercase`；只有拉丁小标（`kicker`、`EYEBROW`）可以。
- 单位与数字用等宽字体 + `font-variant-numeric: tabular-nums`，让列表纵向对齐。

## 2. 色彩：一个强调色，一个危险色，其余都是灰

- 主色只出现在**可交互**或**当前状态**上：链接、焦点环、选中项、进度、KPI 图标。
- 灰阶要有 6–8 级（纸 / 面 / 面-2 / 线 / 线-软 / 弱文 / 中文 / 墨），不要临时用 `#888`。
- 浅色主题的阴影要**暖、要淡**：`0 1px 2px rgba(31,26,16,.05)`，大阴影用负扩散做"贴地"感。
- 半透明白（`rgba(255,255,255,.04)`）在浅色上等于不可见；对应的替代是 `rgba(23,20,14,.03)`。
- 语义色与品牌色分开：成功/危险/警告/信息各一个，不要用主色兼职。

## 3. 版式：留白是设计，不是空白

- 8px 基准栅格；卡片间距 12–16px，区块间距 28–32px，页面左右 32px（移动端 18px）。
- **对齐线要少**：一屏内尽量只有一条左对齐线、一条右对齐线。
- 卡片内边距随层级递减：面板 20px、格子 14px、表格单元 12px。
- 页面头部左对齐"eyebrow + 标题 + 一句说明"，动作按钮靠右；不要居中大标题 + 副标题的模板感布局。
- 移动端不是"缩小版桌面"：侧栏变抽屉，表格变两行信息卡，筛选器折行，KPI 变 2 列。

## 4. 动效：只回答三个问题

动效存在的理由只有：**状态变化从哪来、到哪去、以及是否值得等待**。

- 时长：微交互 120–180ms；进场 220–340ms；页面切换 260–380ms。超过 400ms 的动效必须有内容量支撑。
- 缓动：进场 `cubic-bezier(.16,1,.3,1)`（快出慢收）；弹出 `cubic-bezier(.34,1.56,.64,1)`（轻微回弹）；不要用 `ease-in-out` 处理一切。
- 同时动的属性 ≤ 2 个（通常 opacity + translateY）。
- **进场动画必须错峰**：列表项按 `nth-child` 每项延迟 30–45ms，体现"依次落位"。
- 数据可视化：柱状图 `transform: scaleY(0)→1`，`transform-box: fill-box`；环形图整体淡入 + 轻微旋转；数字用 JS 补间（`countUp`）。
- 交互反馈要"有重量"：按钮按下 `scale(.985)`，悬停上浮 1px + 阴影加深，不要放大。
- 导航当前项用**滑动的指示条**或淡入的底纹，而不是突然变色。
- 必须支持 `prefers-reduced-motion: reduce`：关闭位移与缩放，只保留透明度变化。
- 不要给所有东西都加动画。**滚动视差、鼠标跟随光斑、无限旋转的装饰**是最典型的廉价感来源。

## 5. 反模式（看到就改）

- 紫蓝渐变 + 玻璃拟态 + 全局 glow —— 模板站三件套。
- 每个卡片都有不同颜色、不同透明度、不同阴影。
- 图标与文字基线不齐；图标尺寸混用 14/16/18px。
- 表格没有 hover 反馈、数值不右对齐、空状态只有一行灰字。
- 弹窗宽度用 90vw 且内容贴边；没有关闭按钮焦点管理。
- emoji 当图标。
- 深色主题的 `rgba(255,255,255,.0x)` 直接搬进浅色主题。
- 所有文字 10px，靠"密"制造专业感——真实用户会放大页面。

## 6. 落地流程（本仓库）

1. 读 `web/index.html` 与 `web/assets/pages/*.js` 的模板字符串，**只使用已存在的 class 语义**；不要为了样式去改结构。
2. 在 `app.css` 顶部定义完整 token（颜色 / 圆角 / 阴影 / 缓动 / 字号 / 层级）。
3. 先写布局骨架（shell → page → panel → table），再写组件，最后写动效。
4. 动效统一放在文件末尾的 `Animations` 段，并且都能被 `prefers-reduced-motion` 关闭。
5. 新增视觉能力时优先用 CSS 变量与 `color-mix()`，不要新增构建步骤、外部字体或 CDN。
6. 交付前检查：无横向滚动（≤1280 / 768 / 390 三档）、焦点可见、对比度 ≥ 4.5:1、无 8px 正文。

## 7. 自检清单

- [ ] 一句话说得清这个界面的隐喻
- [ ] 只有 1 个强调色 + 1 个危险色
- [ ] 正文 ≥ 13px，辅助 ≥ 11px
- [ ] 三种圆角以内、两级阴影以内
- [ ] 列表进场有错峰，时长 < 400ms
- [ ] 键盘 tab 能走完主流程，焦点环清晰
- [ ] 1280 / 768 / 390 三档无横向滚动
- [ ] 关掉动画后功能完全不受影响
